# WEB DEVELOPMENT

This repository contains all the activities and practical work completed as part of the Web Development course.

## 📁 MSE 1 Activity

The `MSE 1 Activity` folder contains 10 individual activity folders.

- Each Activity folder contains the respective source code.
- The corresponding outputs and results are provided in PDF format.

## 📁 MSE 2 Activity

The `MSE 2 Activity` folder is organised into two separate folders:

- **Codes:** Contains all the source code files for the activities.
- **Outputs:** Contains PDF files demonstrating the outputs and results of the respective activities.

## Purpose

This repository is maintained to organise, store, and showcase all Web Development MSE practical activities, their source codes, and corresponding outputs.
